Backend API Endpoints

GET /api/profile → returns saved profile (personal info, skills, experiences).

POST /api/profile → saves/updates profile (personal info, skills) and experiences.

POST /api/generate-resume → body: { jobDescription, jobTitle?, companyName?, tone? }, returns tailored resume JSON.

POST /api/generate-cover-letter → same body, returns { coverLetter }.
